# BIT Activation Witness

BIT first diagnoses a bottleneck and assigns a `priority_heuristic`. That score
orders verification work; it is not an activation lower bound.

A positive `certified_activation_gain` requires all of the following:

- an intervention law;
- a resource-matched baseline;
- a unit and validity domain;
- a predeclared stopping rule;
- a resource ledger;
- content-addressed evidence; and
- an independent verifier reference.

Without this witness, `lower_bound=0`, `coordinate_reported=false`, and the
inversion certificate abstains. The candidate remains useful as a repair plan.
