# Python And TypeScript Contract

Python is the semantic reference implementation. PIC-TS provides the same
public report decisions for AFST, Phase Lab, BIT, SQOT, ALT, TRC, and explicit
operations.

The versioned machine-readable contract is
[`../contracts/v1.1/pic-cross-language-contract.json`](../contracts/v1.1/pic-cross-language-contract.json).
It fixes decision order, unknown semantics, non-claim flags, residual kinds,
and a cross-language canonical operation digest. CI must fail when a public
report is unregistered, nondeterministic, or differs without a documented
language-specific reason.
