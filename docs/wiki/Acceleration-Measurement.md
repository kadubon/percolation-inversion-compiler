# Acceleration Measurement

Compare a baseline and candidate under the same observation protocol, constraint
frame, receiver family, resource envelope, fixed horizon, stopping rule, and
evidence policy.

Higher is better for verification yield, receiver reuse, and certified capital
gain. Lower is better for time-to-verified, residual half-life, resource cost,
and absolute error correlation.

Use an accelerator claim only when `accepted=true` and
`acceleration_metrics_certified=true`. This is a finite protocol result, not
proof of real ASI.
