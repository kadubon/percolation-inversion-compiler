# Python TypeScript Compatibility

Python PIC defines canonical semantics. PIC-TS mirrors public schemas, residual
kinds, ordering, non-claim flags, operation JCS digests and Ed25519 signatures,
and the runtime acceleration normal form.

The versioned contract is in
`contracts/v1.1/pic-cross-language-contract.json`. Legacy kebab-case
TypeScript schemas remain compatibility-only; canonical new report schemas use
CamelCase names.
