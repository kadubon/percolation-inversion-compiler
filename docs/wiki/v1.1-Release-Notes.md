# v1.1 Release Notes

Version 1.1 adds strict input boundaries, unknown-value semantics, witness-only
BIT gain, measured SQOT costs, rechecked ALT lift, finite TRC traces, explicit
signed operations, and paired resource-matched acceleration measurement.

Existing v1 command names remain available. Inputs that relied on numeric-string
or string-boolean coercion must be corrected. Runtime task admission no longer
pretends that a provider executed; it reports `not_dispatched`.

The release does not claim real ASI, legal authority, automatic provider
execution, or physical outcome proof.
